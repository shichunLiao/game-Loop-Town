## 1. 修正前截圖（證據）
- 環境：共用電腦 Linux，Godot 4.6.3 stable，`xvfb-run` + `--rendering-driver opengl3`（Mesa llvmpipe 軟體渲染），1280×720。用 repo 內建的截圖參數，沒有改程式：
  `godot --rendering-driver opengl3 --path . -- --capture=<輸出.png> --room=<房間id>`
- 房間：`town_entrance`、`town_hub`、`wax_museum`、`old_theater`、`clock_tower`，各取起始位置一張，5 張退出碼皆 0。
- 截圖未放進 repo（避免加大二進位檔），存在 Rakazo 共用電腦 `bots/cmwgil60xbhz8sgqes5snme7v/lt/shots/`：5 張原圖在 `before/`（附各自 log），拼圖 `lt1-before-contact.jpg`，局部放大（霧中鎮口、美術館）`lt1-before-zoom.jpg`。實作後的「修正後」截圖會和修正一起放進 repo 的對照文件。
- 注意：軟體渲染與 Mac（Metal／OpenGL）色彩可能略有差異，最終以士淳 Mac 上的觀感為準。

## 2. 診斷（看圖＋量測）
1. **明度幾乎一樣**：`town_entrance.png` 中玩家身體框 (140,520)-(180,600) 平均灰階 **51.7**，緊鄰背景框 (200,520)-(260,600) **55.2**，差 3.5／255。角色靠的是輪廓，而輪廓色和背景相近。
2. **背景跟前景一樣清楚**：中景建築、花盆、欄杆和角色同樣銳利、同樣高細節、同樣飽和，沒有「越遠越淡／越暗」的空氣透視。只有最遠層 `exploration_backdrop.gd` 有 `Parallax2D`（scroll_scale 0.12）和染色。
3. **角色沒有落地感**：腳下沒有接觸陰影；玩家只有 1.4px、色號 `70a5ae` 的細描邊（`exploration_player.gd:407-413`），在青灰背景上幾乎看不到。
4. **色溫沒有分開**：角色是棕褐色系，背景也是暖棕＋青灰，角色沒有自己的色域。

## 3. 修正選項（都不改畫風、不重畫）
| 選項 | 內容 | 改哪裡 | 誰做 | 風險 |
|---|---|---|---|---|

| C 接觸陰影 | 腳下半透明橢圓陰影，隨跳躍高度變淡 | 玩家／NPC／敵人節點 | Claude Code | 幾乎無 |
