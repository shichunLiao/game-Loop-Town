## 变更

- 左右进入方向统一；出生点向道路内部偏移，高台采用独立落脚距离；到达入口带返回保护。
- 镇口—东街、枯井—火海两段连廊的重叠出口拆分；镇口的环路返回口设在左侧。
- 新手村五个区域及对应镇内连廊使用连续地面。
- 水平后排中景改实色覆盖；竖向关卡采用连续景墙与贯穿楼层的实色承重柱，远层增加纵向展开。
- 新增蜡像竖井、倒悬之井、钟楼三张不透明竖向背景。
- 莫里斯改为 840 生命、三个阶段、六种技能与独立姿态图集；切换阶段从该阶段的新招式开始。
