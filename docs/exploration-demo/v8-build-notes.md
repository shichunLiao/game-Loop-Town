# Demo 8 修正记录

日期：2026-10-18。引擎：Godot 4.6.3，OpenGL Compatibility。

## 具体原因与修改

1. V7 将通用挑战平台的支撑批量套用到街区，产生了挡住房屋的石砌楔形高柱。V8 删除镇内横向区域的这类平台和绘制，保留连续街基。
2. 原高处支路入口随石台移除会失去落脚处。入口改为地面侧门，增加手动进入逻辑，侧门碰撞不阻挡主街，避免改成地面后产生自动误切图。
3. town_depth_v7 的实际图集分界约在 y=470；原先的 y=512 切割混入相邻构件。改写四个裁切区域，保留原始 PNG。
4. 图像外接框底部不等于建筑主体底部。增加基于主体不透明底边的落地锚点；街道构件按地面放置，竖井细节按实际平台放置。
5. 同步移动道路机关任务目标，保留门组 ID、物品 ID 和线索状态。
6. 街边告示牌补上双支脚和底座；屋顶保留可识别的记忆拾取物，去掉不合适的悬空桌子表现。

v8-postoffice.png、v8-grounded-courtyard.png 对应用户反馈的两处街景。另有西街、钟楼侧门、邮局屋顶、东街、室内与井道画面。运行和导入日志保存在同目录。
