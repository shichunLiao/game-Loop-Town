# Demo 4 制作记录

已使用 Godot 实际启动输出花店外观、打开后的室内、破窗和镜头平移前后的视口图。镜头画面使用相同人物世界位置、不同镜头横向偏移，建筑与人物及地面一起移动。此记录不等同于完整通关。

本轮没有新增或运行自动化测试，也没有完整人工通关。人物动作与其他既有战斗功能仍属于之前的初版范围；室内是同地图中的剖面空间。
