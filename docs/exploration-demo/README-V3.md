# 回环镇 · 动作探索 Demo 3

按《完整提示词》《回环镇·剧情 5.0》和已确认的手绘哥特方向继续制作。本版更新战斗、人物原型、实体通路与多层中景。

## 启动

完整解压 `LoopTownDemo-v3-Windows.zip`，运行其中的 `LoopTownDemo.exe`。同目录的 `LoopTownEngine.exe` 和 `.pck` 必须保留，无需安装 Godot。项目内启动位置为 `dist/LoopTownDemo-v3/`。启动器使用 Windows .NET Framework 4.x。

在 Godot 中打开工程根目录的 `project.godot`，按 F5。使用本机 Godot 4.6.3 / GL Compatibility。新入口为 `scenes/exploration/ExplorationDemo.tscn`。上一版运行包留在 `dist/LoopTownDemo`。

标题页的“人物与敌人图鉴”可以查看全部角色。

## 操作与技能

| 操作 | 按键 / 解锁阶段 |
| --- | --- |
| 移动 / 跳跃 | A、D 或方向键 / Space |
| 笔记本攻击，连按形成三连击 | J，初始 |
| 向上攻击 / 空中向下攻击并命中反弹 | W + J / S + J |
| 穿过脚下的单向平台向下落 | S + Space，不影响实心地面 |
| 大剪刀强化近战、剪线 | 蜡像馆取得剪刀后，J / E |
| 剪刃突进，消耗 25 墨光 | K，取得大剪刀后 |
| 恢复 30 生命，消耗 50 墨光 | H |
| 交谈、调查、转镜、拉杆、存档 | E |
| 二段跳 / 藤蔓攀爬 | Space / W、S，剧院后台解锁 |
| 冲刺，带短暂无敌 | Shift，井底解锁 |
| 缓时 2.8 秒，消耗 35 墨光，冷却 9 秒 | Q，钟楼中层解锁 |
| 全域地图 / 笔记本与能力表 | M / Tab |
| 暂停、关闭覆盖层 / 返回存档灯 | Esc / R |

命中恢复 8 墨光，平时每秒恢复 7。路灯恢复全部生命与墨光并保存。正常跨地图保留生命和墨光；受伤后短暂无敌，长距离坠落会死亡。

攻击具有准备、有效、收招阶段，使用 Area2D 攻击区与受击区相交判定。NPC 不具有敌方受击区。缓时影响敌人、蜡弹、周期危险和升降台。

## 人物初版

| 类别 | 内容 |
| --- | --- |
| 主角 × 1 | 大帽侦探，独立透明立绘，笔记本和剪刀，跑跳、连击、技能、受伤与重生 |
| NPC × 8 | 点灯人、抱布包的女人、提水老人、缝衣匠、旧书商、检票人、钟表修理匠、站务员；每位有独立外观和两段对话，交谈时短暂停顿 |
| 怪物 × 8 | 踉跄蜡像、烛泪喷吐者、断线木偶、红线飞蛾、黑泥爬行者、井底回声、发条哨兵、火中的居民 |
| 行为 | 巡逻近战、远程蜡弹、预警突进、飞行追逐、正面减伤、迟疑低伤攻击；部分种类共用行为，但外形与数值不同 |
| Boss × 1 | 莫里斯，620 生命，三个血量阶段；扇形熔蜡弹、近身突进、召唤至多两个蜡像替身，阶段越后出手越快 |

莫里斯位于蜡像馆熔炉区，击败后打开地下镜室的机械锁，回复少量生命并保存。环境图不包含烘焙人物，所有角色均独立放入场景。

人物目前采用透明立绘配合程序摆动、倾斜、闪烁和攻击弧光。完整逐帧动画、魂穿反打、蜡化结局、其他 Boss 和长篇过场仍待后续细化。

## 地图与探索路线

世界为 **18 个主要区域 + 23 段实体连接地图**，共 41 个场景、46 对边界连接。连接地图有实际平台、上行回廊、下行井道、水平连廊与升降台。

沿路牌走到道路尽头自动短暂淡出，载入下一段道路；不再按 E 从门框传送。向上的区域需要实际攀登，井底需要逐段下行。主路分支放在上层平台，避免走过地面时误入。封路栅栏有真实碰撞，解锁后打开。地图只查看路线，已取消点击路灯传送；死亡返回存档灯仍保留。

1. 镇口取信，与点灯人交谈，向右经连廊进入西环。
2. 西环上层支路通往蜡像巷，再沿上行路线到蜡像馆。取得大剪刀后回熔炉战场击败莫里斯。
3. 下到七镜地下室，按 **2、3、4、1、2、4、3** 调整镜子，取得蜡像印记。
4. 经广场、东环上行到剧院，剪断三道红线并拉开返程拉杆。后台布偶给予剧院印记、二段跳和藤蔓攀爬；此时可返回镜室探索档案室支路。
5. 东环下行到枯井，带布偶进入井道。小段下跳并借平台或藤蔓落脚；取得合照、井底印记与冲刺后黑泥上涌，排水闸是一条逃生路线。
6. 三印记开启广场的钟楼路线，经外庭、七层钟楼抵达楼顶。中层看守记录解锁缓时，塔内有中继存档灯。
7. 触碰发条记忆进入火海阶段，可以选择留下，或走实际下行路线进入火海。火中的居民伤害较低，对应剧本设想。
8. 重访井底补全记忆，到停钟之处做选择。满足条件后沿连廊去火车站。三条结局目前以选择和文字呈现。

保存兼容上一版 `exploration_v2.json`。旧档已有蜡像印记时视为通过莫里斯，已有看守记录时补上缓时。体验新增完整战斗可从标题开始新游戏。原故事存档 `slot_0.save` 属于另一套入口。

## 美术与资源

保留原有 18 张环境 PNG，新增 **16 张透明资源图集**，共 34 张 PNG。新增图集包括：6 张角色图集（主角、Boss、8 NPC、8 怪物）、7 张区域中景图集（28 个不同场景簇）、3 张地形变体图集（12 种石、木、金属外观）。

中景包含民居、书店、水车、门庭、橱窗、熔炉、镜室、包厢、吊台、戏服、井房、枯林、根须、井环、钟面、齿轮、摆锤、火海废墟和站台等。每个区域有固定地标区块、不同平台跨度与高低布局、独立种子和不同中景组合；左上角显示所在区块名称。

层级：远景 `.12` → 远处建筑 `.27` → 中层建筑 `.53` → 近处建筑 `.82` → 地形与人物 → 前景。纵向滚动速度独立配置。背景不承担碰撞，碰撞顶边与图集裁切区域对齐。

资源在 `assets/environments/exploration/`。尺寸、alpha 与散列见 `asset-manifest.json`；新增提示词见 `v3-art-prompts.json`，旧环境提示词见 `ART_PROMPTS.md`。均使用内置 imagegen 制作，原 PNG 保留，裁切只记录为图集元数据。

`world-map.png` 为 3840×2160 全域图，与运行时 M 地图共用数据。18 个区域绘为区块，23 段实体通路绘为连线，当前道路高亮为金色。

## 继续扩展

- `data/exploration/world.json`：地图、平台、出生点、机关、人物位置与路线。
- `actors.json`：人物、敌人数值、阶段能力；`art-regions.json`：图集裁切区域。
- `tools/dev/build_exploration_world.py` 及 `build_exploration_upgrade.py`：世界数据生成源，重新运行会覆盖直接修改的世界 JSON。
- `catalog_exploration_art.py` 只读取透明边界生成元数据，不改原图。
- `assets/environments/exploration/atlases/` 提供 58 个独立 AtlasTexture `.tres`，可直接拖入 Godot 使用，无需自行裁图。
- `scenes/exploration/maps/` 中 41 个地图可分别 F6 运行。
- 脚本按 Player、Enemy、Boss、NPC、HitArea、Projectile、Passage、Backdrop、HUD 等职责拆分，方便替换动画和扩展内容。
- 素材包包含图像、材质、图集及人物数据；源码包包含场景、脚本、世界与生成工具。
