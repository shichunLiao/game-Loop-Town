# 回环镇 · Demo 8 修正版

完整解压游戏包，运行 **LoopTownDemo.exe**。Godot 源码使用 4.6.3，打开 project.godot 后按 F5。

## 本轮修正

### 镇内街道

删除镇口、西环、广场、东环、钟楼外庭及水平街道连廊前方的通用石台、石柱和石砌斜撑。街面保持连续实体基础，房屋前不再堆放挑战平台。

邮局、书店、戏服店的可探索高处依附实际屋顶，由贴墙木楼梯连接。屋顶使用单独的轮廓碰撞，未在房屋原画上覆盖通用平台。

原来架在高台上的街区分支落到街边侧门。靠近后按 **E** 调查、解锁或进入；已经开启的侧门也需要按 E，经过它不会自动换图。关闭的侧门限制支路进入，玩家可以沿主街继续通行。

穿门后仍加载原有实体楼梯或井道，上下区域之间需要实际攀登。主街左右边界继续自动换图，遵循“从左离开 → 下一段右侧出现”。道路、机关、线索和居民任务的身份编号保留，旧存档继续使用。

### 中景落地

庭院图集的上下两排不在图像正中分开。此前按四等分裁切，把下排屋顶碎片切进了上排温室和洗衣拱廊，并把下排屋顶尖角切掉。本轮改为按实际分界裁切，原 PNG 未修改。

增加 art-anchors.json，记录建筑主体的实际落地线。后排构件、街边道具和房屋按这个锚点放置，忽略透明边缘、孤立碎片和细小拖尾。水平构件落在街道地面，竖井构件对齐实际楼层平台，去掉任意悬空的高度偏移。

街边告示牌补上清楚的双支脚、底座和木板边框。屋顶线索使用记忆拾取物表现，避免把普通桌子悬在屋檐上。

## 操作

| 按键 | 功能 |
|---|---|
| A / D / 方向键 | 移动 |
| Space | 跳跃，解锁后二段跳 |
| J / K | 普通攻击 / 当前武器技能 |
| W + J / 空中 S + J | 上挑 / 下劈 |
| E | 对话、调查、房门、街边支路、道路机关和吊笼 |
| H | 消耗墨光恢复生命 |
| Shift / Q | 解锁后冲刺 / 缓时 |
| W / S | 解锁后攀爬藤蔓 |
| S + Space | 穿下单向平台 |
| L / M / Tab | 任务 / 地图 / 笔记 |
| R / Esc | 返回路灯 / 暂停 |

## 内容与扩展

保留 69 个独立场景、92 条有向道路连接、28 个室内、任务、阶段武器和三阶段莫里斯。竖向背景保持固定。

build_exploration_v8.py 编写本轮街区修正与构件落点，catalog_exploration_art.py 生成裁切及落地元数据。运行 build_exploration_world.py 可重新生成场景数据；图集原图、裁切范围和落地锚点一起交付。
