# 回环镇 · Demo 6

完整解压 Windows 包，运行 LoopTownDemo.exe。Godot 源码使用 4.6.3，导入 project.godot 后按 F5。

## 本轮修正

### 左右地图衔接

按照「左边界离开 → 下一段道路右侧出现，继续向左深入」处理，反方向同理。连廊的返回口与来路使用相反朝向；出生位置向道路内部留出距离，高台出生点保留在落脚平台上。刚到达的入口带有返回保护。

另外修正两段连接：镇口与东街的环路、枯井与火海的连廊。此前它们的两个返回口可能落在同一侧同一位置，持续移动会选中原地图。现在两个出口分开，并调整了镇口左侧和枯井支路的实际落脚平台。

室内仍通过独立场景的房门进出，原来的线索、任务与机关存档继续兼容。

### 中远景与竖向连续性

房屋后排的建筑图层使用实色覆盖。景深通过色温、明暗、大小区分。剪影外的空白保留镂空。

竖向关卡移除分散叠放的半透明中景块。蜡像竖井、倒悬之井、钟楼分别使用连续的完整景墙；远层随纵向镜头展开，固定中层采用贯穿井道的承重柱。上层、中层、底层具有不同的橱窗、管道、根须、排水结构、钟面或发条机房，减少矩形接缝与重复。

### 新手村地面

镇口、西环、广场、东环、钟楼外庭及它们之间的镇内连接道路使用连续地面，保留屋顶和高台支路。蜡像馆、剧院、井道和火海的后续挑战地形保留。

## 三阶段莫里斯

生命 840。战斗有入场、预警、攻击、收招、阶段切换和死亡状态。攻击开始后方向会锁定，可以绕后；普通命中不会无限打断技能。阶段切换清理旧弹幕、分身和地面攻击，并补充少量墨光。

| 阶段 | 外形与技能 | 应对 |
|---|---|---|
| 第一阶段：蜡匠的执念 | 抬臂蓄力、三发烛泪散射、蜡刃横扫、单点熔蜡地刺 | 利用弹道间隙，跳起或绕到横扫背后，离开地刺标记 |
| 第二阶段：蜡壳裂开 | 熔裂蜡壳、五发散射、熔蜡突进、两具假身、双点地刺和残留蜡池 | 跳过突进；真身保留暖色眼光，冷色假身一击破碎 |
| 第三阶段：熔炉中的真身 | 暴露熔炉核心、烛雨、双轮散射、三点地刺、加速突进 | 寻找烛雨预警间隙，持续换位，利用技能结束后的空档 |

每种攻击使用实际判定。地刺与烛雨先显示落点，突进和横扫先显示方向与距离，分身具有独立追击攻击。Boss 场内移除旧的周期地面喷蜡，保留 Boss 自身的技能预警。胜利后清理技能、解开战场边界并保存地窖解锁进度。

标题页新增「莫里斯演练」：直接装备大剪刀进入战场，演练使用单独存档，不影响主线。死亡后回到演练起点；再次从标题进入可重新挑战。

## 操作

| 按键 | 功能 |
|---|---|
| A / D / 方向键 | 移动 |
| Space | 跳跃，解锁后二段跳 |
| J | 三连击；W + J 上挑，空中 S + J 下劈 |
| K | 当前阶段武器技能 |
| E | 对话、调查、进出室内、操作门桥机关 |
| H | 消耗 50 墨光恢复 30 生命 |
| Shift | 解锁后冲刺 |
| Q | 解锁后缓时 |
| W / S | 解锁后攀爬藤蔓 |
| S + Space | 穿下单向平台 |
| L / M / Tab | 任务 / 地图 / 笔记 |
| R | 返回路灯或演练起点 |
| Esc | 暂停 / 关闭面板 |

主线保留 18 个区域、23 段实体通路、28 个独立室内、47 处 NPC、10 步主线、8 个居民委托、14 组道路机关和五阶段武器。继续旧进度请选择「继续上一次探索」；「新探索」会重新开始。

## 素材与扩展

新增 3 张不透明竖向景墙、2 张正式 Boss 动作/形态图集，以及 2 张保留的过程稿；全素材库共 68 张 PNG。新增素材由内置 image_gen 制作，提示词见 v6-art-prompts.json 和 v6-art-refinement-prompts.json。

tools/dev/build_exploration_v6.py 编写本轮道路、景墙和地形修改；执行 build_exploration_world.py 可重新生成场景数据。scripts/exploration/exploration_boss.gd、exploration_boss_attack.gd、exploration_morris_double.gd 分别负责 Boss、地面技能和假身。

## 当前范围

进行了引擎导入、编译、实际场景和战斗画面预览，并运行最终 Windows 包。未进行自动化测试或完整剧情通关；尚未逐条实际游玩全部通路。Boss 使用姿态图集与程序动画，战斗数值仍可调整。其他章节的 Boss 尚未新增。
