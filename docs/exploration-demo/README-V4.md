# 回环镇 · Demo 4：固定建筑与街区交互

## 启动

完整解压 `LoopTownDemo-v4-Windows.zip`，双击 `LoopTownDemo.exe`。保留同目录的 `LoopTownEngine.exe` 和 `LoopTownDemo.pck`。无需安装 Godot；启动器使用 Windows .NET Framework 4.x。当前工程打开 `project.godot` 按 F5 同样进入新版。

建议开始新游戏体验镇口花店。已有探索存档仍可继续，但可能从较后面的存档灯开始。

## 本轮更新

### 房屋固定到关卡坐标

删除原来在三个视差层反复复制建筑的方式。可接近的建筑、门口、窗户、室内物品、家具和阳台统一放在 `WorldArchitecture` 的普通 Node2D 下。它们与地形一起移动，不读取镜头位置，也不使用屏幕锚点或 Parallax2D。远处天际线保留背景视差，并降低明暗对比以区分远近。

修正交互点以世界坐标计算距离；房门和 NPC 按更近的目标选择，避免站在门口仍被较远的 NPC 抢占交互。

### 增加建筑与街景

使用内置 imagegen 新增 22 张 PNG：

- 16 张独立建筑：花店、面包房、药铺、书店、水车工坊、旅舍、修表铺、邮局、蜡像陈列店、蜡匠工棚、剧院售票亭、戏服间、守夜屋、发条工房、余烬民居、候车室。
- 4 张室内剖面：居住店铺、蜡匠工作室、后台缝纫室、机械维护室。
- 2 张街景图集，共 8 个不同摆件：饮水台、花车、长椅行李、剧院道具车、压力阀、界碑根须、告示灯架、齿轮工具车。

全域配置 50 处固定建筑与结构，共 36 种建筑 / 结构外观，其中 28 处房屋可以开门调查。每间房屋只放置一次完整外立面，不再为多个深度层复制同一栋房子。同一区域的建筑采用不同素材；连接道路使用不同结构地标和小摆件。部分建筑类型仍会跨区域复用。

### 实际交互

1. 靠近门口按 **E**：门的外立面淡出，露出同一关卡坐标中的室内；玩家位置不会传送。
2. 向屋内桌边走，按 **E** 调查纸页：获得一条可在 Tab 笔记本查看的环境线索，并恢复少量墨光。纸页每间仅领取一次。
3. 回到门口按 **E** 离开，或走出建筑范围后关闭剖面。
4. 靠近窗灯按 **E** 切换灯光。较高的窗户可借助阳台跳跃接近。
5. 用 **J** 攻击窗户：破损后熄灯、留下碎片与裂痕，并一次性恢复少量墨光。破损状态、灯光和线索状态会保存。
6. 阳台与屋内桌面有真实单向碰撞。按 **S + Space** 可穿下平台。
7. 非房屋的中景结构可按 **E** 调查对应痕迹。

室内采用侧面剖面表现，与外部街道位于同一地图空间；当前没有另建完整室内地图。窗灯按一处可操作窗格和整栋暖光反馈表现，后续仍可逐窗细化。

## 其他操作

A/D 移动；Space 跳跃；J 攻击；W/S + J 方向攻击；K 剪刃；H 恢复；E 调查或交谈；M 全域地图；Tab 笔记本；Esc 暂停。剧院解锁二段跳与攀爬，井底解锁 Shift 冲刺，钟楼中层解锁 Q 缓时。

保留上一版的 18 个主要区域、23 段实体通路、8 位 NPC、8 类敌人和莫里斯原型战。主线从西环前往蜡像馆、击败莫里斯并完成七镜，再经剧院、井底、钟楼继续。原有角色与战斗仍是初版。

## 资源与继续制作

- `assets/environments/exploration/architecture/`：16 张建筑、外立面剖面材质。
- `interiors/`：4 张室内图。
- `midgrounds/street_props_a、street_props_b.png`：新增街景图集。
- `atlases/`：已经裁去多余留白的 AtlasTexture，可直接拖入 Godot。原始 PNG 没有经过脚本改图。
- `data/exploration/world.json`：每栋建筑的资源、坐标、名称、室内类型、阳台与线索。
- `tools/dev/build_exploration_architecture.py`：本轮建筑布置生成源。
- `scripts/exploration/exploration_building.gd`：固定坐标建筑与状态；`exploration_building_feature.gd`：交互点与受击区。
- `v4-art-prompts.json`：本轮完整生成提示词；`asset-manifest.json`：所有图像的尺寸、透明通道、散列和建筑统计。

新增线索均为场景物件的补充描述，不改写剧情主线和最终真相。

## 运行记录范围

本轮使用 Godot 导入、编译并实际输出建筑外观、开门剖面、窗灯和不同镜头位置的画面。没有新增或运行自动化测试，也没有完整人工通关；不将旧版验证结果作为本版结论。
