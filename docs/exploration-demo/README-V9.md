# 回环镇 · Demo 8 · 剧情 1.1 文本版

Godot 源码使用 4.6.3，打开 project.godot 后按 F5。本版只替换剧情设定与文字，地图、路线、机关和战斗沿用 Demo 8。

## 本轮修改

按《剧情 1.1》替换全部面向玩家的文字。主角改为回乡参加姑姑葬礼的画家杰利；枯井下挖出的遗骸被确认是玲，刑警的传唤成为调查起点。丰收祭当天的美术室、两张演出海报、剧院的布偶、钟声与解离，取代原先的七年前火灾、247 次循环和蜡像订单。

`tools/dev/build_exploration_v9.py` 在 v8 之后运行，按原文逐条替换 `data/exploration` 下 world、actors、quests、weapons 四个文件里的文字，并把 world 版本号标为 9。替换表写在脚本里；任何一条原文没有找到都会列出来。房间、旗标、道路、居民与道具的身份编号一律不变，旧存档继续使用。

脚本里直接写出的文字同步改在 `scripts/exploration`：标题、人物图鉴、任务提示、Boss 招式与阶段名、钟楼顶的选择和三个结局。

## 尚未改动

关卡顺序仍是 美术馆 → 剧院 → 枯井 → 钟楼 → 丰收祭之夜 → 枯井 → 停钟之处 → 车站，剧本顺序为 美术馆 → 剧院 → 钟楼 → 枯井。守钟人的选择在剧本里发生在最后一次下井之前，现在仍在之后。

沃伊德、守钟人、弗瑞、玲四场 Boss 战，弗瑞视角切换，以及撕碎、入画、破败的人偶、布偶等战败结局尚未实现。梅·莫里沿用莫里斯的三阶段招式，只改了名称。刑警尚未作为角色出现，只出现在文字里。

美术与音效没有替换：美术馆区域仍是蜡像与熔炉的画面，Boss 立绘仍是蜡匠，丰收祭之夜仍是燃烧的街道。
