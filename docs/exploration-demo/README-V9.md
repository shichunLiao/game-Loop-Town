# 回环镇 · Demo 9 · 剧情 1.1 版

Godot 源码使用 4.6.3，打开 project.godot 后按 F5。本版替换剧情设定与文字，把主线改为剧本顺序，并新增沃伊德、守钟人、弗瑞与玲四段玩法；Demo 9 由 Codex 绘制五位剧情角色的全部新立绘与美术馆区域三张背景（见 [v9 构建记录](v9-build-notes.md)）。其余地图、机关和战斗沿用 Demo 8。

## 本轮修改

按《剧情 1.1》替换全部面向玩家的文字。主角改为回乡参加姑姑葬礼的画家杰利；枯井下挖出的遗骸被确认是玲，刑警的传唤成为调查起点。丰收祭当天的美术室、两张演出海报、剧院的布偶、钟声与解离，取代原先的七年前火灾、247 次循环和蜡像订单。

`tools/dev/build_exploration_v9.py` 在 v8 之后运行，按原文逐条替换 `data/exploration` 下 world、actors、quests、weapons 四个文件里的文字，并把 world 版本号标为 9。替换表写在脚本里；任何一条原文没有找到都会列出来。房间、旗标、道路、居民与道具的身份编号一律不变，旧存档继续使用。

脚本里直接写出的文字同步改在 `scripts/exploration`：标题、人物图鉴、任务提示、Boss 招式与阶段名、钟楼顶的选择和三个结局。

### 主线顺序

剧本顺序为 美术馆 → 剧院 → 钟楼 → 枯井，v9 的 `reorder_v9` 按此调整：

1. 美术馆：美工刀、梅·莫里、七面镜子，取得美术馆印记。
2. 剧院：剪断红线，在后台取得玲的布偶、剧院印记、二段跳、藤蔓攀爬与冲刺。冲刺原在井底，提前到剧院，钟楼的攀爬能力与 Demo 8 保持一致。
3. 钟楼：广场大门只需美术馆与剧院两枚印记。中层守钟人的笔记给缓时，顶层想起丰收祭的钟声。
4. 钟楼顶：守钟人摘下帽子，露出杰利的脸。「听守钟人的话」进入结局「钟声之后」；「我要知道真相」记下 `keeper_truth`，钟声响起，通往丰收祭之夜的门打开。
5. 丰收祭之夜 → 枯井：东街路障、钟顶回廊与旧井房三道门都改为需要 `keeper_truth`，枯井因此成为最后一关。走到警戒线旁的井口，触发弗瑞。
6. 倒悬之井：被推下井后与玲战斗。击败后合照与井底印记落下，走到角落找到真正的玲，想起那天真正发生的事，按「醒来」进入结局「迟到的鲜花」。

主线任务列表按上述顺序重排，「守钟人的选择」改为追踪 `keeper_truth`。停钟之处保留「让钟声倒带」（回溯，带着已想起的记忆重新开始）；那里的「守钟人留下的帽子」只给提示，不再结束探索。

读取 Demo 8 存档时：已有剧院印记即补上冲刺；已想起钟声且到过丰收祭之夜或井底深处，即视为已经回应守钟人。已想起井边那一天的存档不再重演弗瑞与玲。存档点在井底但还没被弗瑞推下去的，回到枯井；存档点在守钟人那几道门后面但还没回应他的，回到镇口，以免被困。

### 沃伊德（剧院 Boss）

后台舞台中央的沃伊德用红线操控四只人偶，招式依次为丝线操控、丝线鞭打（被缠住减速并持续掉血）、丝线绞杀（圈住出手时的位置，留在圈内触发结局「破败的人偶」）与第三阶段的暴走丝线。用刀砍中线结即剪断红线，对应人偶倒下；每剪断一根，他更快但承受伤害更高。被人偶击中会累积「布化」：变慢、出手变慢，六层后美工刀落下只能徒手，八层触发结局「布偶」。两个战败结局都会回溯到最近的路灯。击败后取回布偶与剧院奖励，钟声响起，杰利直接出现在钟楼外庭。实现在 `exploration_void_boss.gd`、`exploration_void_puppet.gd`、`exploration_void_thread.gd`；立绘为 Codex 新画的 `void_idle / void_command / void_lash / void_frenzy`，人偶为 `void_puppet`。

### 守钟人（钟楼追逐）

七层钟楼变成追逐战，由 `exploration_keeper_chase.gd` 管理，数据在 `clock_tower.keeper_chase`。守钟人从塔底开始，始终比杰利高一层，拖延 40 秒也会自己向上。第 2 层有完美版本的梅·莫里，第 4 层有完美版本的沃伊德，都直接从第二阶段开始。守钟人走到顶层或杰利走到顶层出口时，只要还有一个活着，钟声就会响起：杰利退回下方两层，活着的 Boss 回复 30% 生命。追逐期间路灯点不亮，战败回到塔底并重打全部 Boss。脚下会定时伸出有预警的手，墙上的手与纽扣眼睛随楼层增多，光线也逐渐变红。两个都击败后追逐结束，路灯恢复，出口放行；钟楼顶站着守钟人的剪影，选择「我要知道真相」后消散。守钟人立绘为 Codex 新画：追逐中是背对杰利拧发条的 `keeper_back`；钟楼顶杰利走近时转身（`keeper_hidden`，帽檐下看不清五官），再靠近摘下帽子露出杰利的脸（`keeper_unmasked`）。

静态计算确认：只用单跳、不用冲刺即可从地面到达顶层平台。

### 弗瑞（枯井边）

由 `exploration_fury_scene.gd` 管理，数据在 `dry_well.fury_scene`。在地面走到井口附近，触发一段不会失败的过场：杰利注意到井口边深褐色的痕迹，弗瑞出现在身后，画面波动一下，「你想起来了？」，屏幕出现「我得快除掉他。」。警戒线围住场地，弗瑞连续突进三次，杰利躲避，杰利的刀碰不到他。钟声响起、画面一闪，玩家操控的身体换成弗瑞，杰利站到另一边往后退。视角切换没有新增角色，而是给同一个玩家节点换贴图（`ExplorationPlayer.wear`），相机、输入和索敌都不用改。弗瑞的立绘为 Codex 新画的 `fury_idle / fury_lunge`，玩家操控时出拳换成 `fury_punch`。这时只有拳头，左上角的生命条和杰利的血条一起掉，打到只剩 1 点后杰利倒下，弗瑞把他拖到井口：「那你也去死吧」。黑屏，「杰利掉进井口，往下坠。黑暗吞没了他。」，记下 `fury_done`，画面在井底亮起，生命回满。井口检修门改为需要 `fury_done`，所以只能这样下井。

### 玲（井底）

井底原有的取合照、黑泥撤离已移除。玲由 `exploration_ling_boss.gd` 实现，数据在 `well_interior.boss`，需要 `fury_done` 才出现。身体占据蓄水池右半边，战斗中藤蔓封住四周，路灯点不亮，战败回到井底起点、玲回满，不用重演弗瑞。

- 泥浆上涨：每秒上涨 10 / 13 / 16 像素。站进泥里会减速、跳不高；没过胸口 1.5 秒被拖入泥浆，直接回溯。
- 藤蔓抽打：从墙壁、天花板和角落瞄准杰利当前位置，先有红线预警，打中掉血并击退。
- 手抓脚踝：泥面伸出三只手，有预警。站在泥面上被抓住就不能走，2.6 秒内连按空格或 A / D 六下挣脱，否则被拖入泥浆。站在泥面之上时她改用藤蔓。
- 声音干扰（第二阶段起）：倒放童谣，视野变暗约 3 秒，左右方向颠倒 2 秒，开始前有提示。
- 玩家机制（剧本此处空白，这里是提议）：她被藤蔓裹住时打不动。场上有一个发光的藤结，砍断后泥浆退 170 像素、藤蔓松开 5 秒，这段时间泥浆不涨、她不出招，才能伤到本体。藤结会轮流长在地面、左右平台和顶层，被泥浆淹没就换一处。可以沿中央新增的藤蔓攀爬。

击败后怪物崩塌，泥浆退去，藤蔓枯萎，合照与井底印记落下。角落里蹲着真正的玲，靠近按 E：「我找到你了」，再按「醒来」进入结局。

## 尚未改动

清晨 · 小镇车站在剧本中没有对应情节，新主线不再开启车站门；车站与其中的结局保留在地图里，目前到不了。

梅·莫里沿用莫里斯的三阶段招式，只改了名称；雕像替身、撕碎与雕塑化结局、入画与画作化、可推倒的掩体尚未实现。梅战前后的过场和守钟人消散后钟楼瓦解也还没有做成演出。刑警尚未作为角色出现，只出现在文字里。

Demo 9 已替换：梅·莫里（美工刀、右脸黑印、雕像替身、画笔形态）、沃伊德与座位人偶、守钟人、弗瑞、井底的玲（泥浆藤蔓巨体、泥手、角落里真正的玲）均改用 Codex 新立绘；美术馆 · 无尽走廊、七镜画室（地下室与档案室共用）、美术馆前街三张背景改为美术馆题材。Follow-up item 2 已用内置 Codex image_gen 重绘丰收祭之夜远景 `fire.png`（1672×941 RGB）：空白祭典布幡、琥珀灯火、中央钟塔与紫红烟雾，也供后期小镇火灾记忆共用；fire 中景未替换。仍未替换：井口、警戒线、藤蔓、红线与地上的手仍由代码绘制；玲的哭声与喊声只有文字，声音暂用倒放童谣；音效未换。
