# 回环镇 · Demo 8 · 剧情 1.1 版

Godot 源码使用 4.6.3，打开 project.godot 后按 F5。本版替换剧情设定与文字，并把主线改为剧本顺序；地图、机关和战斗沿用 Demo 8。

## 本轮修改

按《剧情 1.1》替换全部面向玩家的文字。主角改为回乡参加姑姑葬礼的画家杰利；枯井下挖出的遗骸被确认是玲，刑警的传唤成为调查起点。丰收祭当天的美术室、两张演出海报、剧院的布偶、钟声与解离，取代原先的七年前火灾、247 次循环和蜡像订单。

`tools/dev/build_exploration_v9.py` 在 v8 之后运行，按原文逐条替换 `data/exploration` 下 world、actors、quests、weapons 四个文件里的文字，并把 world 版本号标为 9。替换表写在脚本里；任何一条原文没有找到都会列出来。房间、旗标、道路、居民与道具的身份编号一律不变，旧存档继续使用。

脚本里直接写出的文字同步改在 `scripts/exploration`：标题、人物图鉴、任务提示、Boss 招式与阶段名、钟楼顶的选择和三个结局。

### 主线顺序

剧本顺序为 美术馆 → 剧院 → 钟楼 → 枯井，v9 的 `reorder_v9` 按此调整：

1. 美术馆：美工刀、梅·莫里、七面镜子，取得美术馆印记。
2. 剧院：剪断红线，在后台取得玲的布偶、剧院印记、二段跳、藤蔓攀爬与冲刺。冲刺原在井底，提前到剧院，钟楼的攀爬能力与 Demo 8 保持一致。
3. 钟楼：广场大门只需美术馆与剧院两枚印记。中层守钟人的笔记给缓时，顶层想起丰收祭的钟声。
4. 钟楼顶：守钟人摘下帽子，露出杰利的脸。「听守钟人的话」进入结局「钟声之后」；「我要知道真相」记下 `keeper_truth`，钟声响起，通往丰收祭之夜的门打开。
5. 丰收祭之夜 → 枯井：东街路障、钟顶回廊与旧井房三道门都改为需要 `keeper_truth`，枯井因此成为最后一关。
6. 倒悬之井：取得美术室的合照与井底印记，再到井底深处想起那天真正发生的事，按「醒来」进入结局「迟到的鲜花」。

主线任务列表按上述顺序重排，「守钟人的选择」改为追踪 `keeper_truth`。停钟之处保留「让钟声倒带」（回溯，带着已想起的记忆重新开始）；那里的「守钟人留下的帽子」只给提示，不再结束探索。

读取 Demo 8 存档时：已有剧院印记即补上冲刺；已想起钟声且到过丰收祭之夜或井底深处，即视为已经回应守钟人。

### 沃伊德（剧院 Boss）

后台舞台中央的沃伊德用红线操控四只人偶，招式依次为丝线操控、丝线鞭打（被缠住减速并持续掉血）、丝线绞杀（圈住出手时的位置，留在圈内触发结局「破败的人偶」）与第三阶段的暴走丝线。用刀砍中线结即剪断红线，对应人偶倒下；每剪断一根，他更快但承受伤害更高。被人偶击中会累积「布化」：变慢、出手变慢，六层后美工刀落下只能徒手，八层触发结局「布偶」。两个战败结局都会回溯到最近的路灯。击败后取回布偶与剧院奖励，钟声响起，杰利直接出现在钟楼外庭。实现在 `exploration_void_boss.gd`、`exploration_void_puppet.gd`、`exploration_void_thread.gd`；立绘暂用检票人素材。

## 尚未改动

清晨 · 小镇车站在剧本中没有对应情节，新主线不再开启车站门；车站与其中的结局保留在地图里，目前到不了。井底仍沿用 Demo 8 的黑泥撤离：先拿合照会触发撤离，之后要再下到井底深处。

守钟人、弗瑞、玲三场 Boss 战，弗瑞视角切换，以及撕碎、入画、破败的人偶、布偶等战败结局尚未实现。梅·莫里沿用莫里斯的三阶段招式，只改了名称。刑警尚未作为角色出现，只出现在文字里。

美术与音效没有替换：美术馆区域仍是蜡像与熔炉的画面，Boss 立绘仍是蜡匠，丰收祭之夜仍是燃烧的街道。
