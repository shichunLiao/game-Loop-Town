# 回环镇 · Demo 7

完整解压 Windows 包，运行 **LoopTownDemo.exe**。源码使用 Godot 4.6.3，导入 project.godot 后按 F5。

## 这次更新

- **实体镇基**：街道下方改为连续厚石墙、砖砌基础和嵌入式拱券；地基有实际碰撞，新手村连续地面保留。
- **固定竖向背景**：所有 17 个竖向场景的建筑背景都在世界坐标中，移除纵向视差和重复覆盖的柱墙。上下移动镜头会看到建筑的不同位置。
- **重排攀登路线**：两座主竖井与 15 段竖向连接通路采用墙边挑台、跨井空隙、宽休息层和侧廊。通路使用四种楼层节奏；单步主路高度差不超过 126，横跨两侧挑台的空隙为 130–180。
- **返程捷径**：七处井道设独立吊笼井。第一次从石廊攀到上层，按 E 接通手柄；之后可呼叫吊笼、进入吊笼按 E 上下运行。上下层有实际停靠位置，解锁和停靠方向写入存档。
- **丰富中景**：新增庭院温室、洗衣拱廊、排水泵、井壁拱券、蜡像陈列、铜管维护台、配重架及剧院侧包厢等 16 种构件，按街区和楼层布置。
- **修正房屋窗光**：移除错位的方形窗灯覆盖，只改变原画实际窗户的颜色。房屋与后排构件仍固定在地图中，房门仍加载独立室内。
- **探索回报**：竖向连接通路增加 15 处可保存的侧廊路记；层级名称与休息台对应，水平街区地标名与实际建筑位置对应。
- **上层出口归位**：倒悬之井与钟楼的上层出口移至实际侧墙，避免前往吊笼时经过中央换图触发区。左右换图继续遵循“从左离开 → 下一段右侧出现”。

## 操作

| 按键 | 功能 |
|---|---|
| A / D / 方向键 | 移动 |
| Space | 跳跃，解锁后二段跳 |
| J | 三连击；W + J 上挑，空中 S + J 下劈 |
| K | 当前武器技能 |
| E | 对话、调查、房门、道路机关、吊笼手柄 |
| H | 消耗 50 墨光恢复 30 生命 |
| Shift / Q | 解锁后冲刺 / 缓时 |
| W / S | 解锁后攀爬藤蔓 |
| S + Space | 穿下单向平台 |
| L / M / Tab | 任务 / 全域地图 / 笔记 |
| R / Esc | 返回路灯 / 暂停 |

18 个主区域、23 段实体连接通路、28 个独立室内、47 处 NPC、八类怪物、任务与三阶段莫里斯继续保留。标题页的“莫里斯演练”使用独立存档。

## 地图与素材

world-map.png 展示全域区域与连接；v7-route-layout.svg 展示读取实际关卡数据生成的四张竖向路线结构图。v7-*.png 为引擎实际画面。

本轮通过内置 imagegen 生成四张构件图集和一张实体材质图集，共 5 张 PNG；全部素材累计 73 张 PNG。提示词见 v7-art-prompts.json，原图与 AtlasTexture 裁切元数据均保留在工程。

参考 [Team Cherry 对遗忘十字路的介绍](https://www.teamcherry.com.au/blog/the-forgotten-crossroads-a-hollow-knight-tour)中互通路径、隐藏捷径和探索回报的组织思路。本版地图和建筑资源按回环镇场景重新构建。

## 继续制作

tools/dev/build_exploration_v7.py 定义本轮地形、楼层、吊笼和构件分布；运行 build_exploration_world.py 重新生成 world.json 与独立地图场景。render_exploration_routes.py 按同一份数据生成路线图。

场景图层分为远景、固定后排构件、可交互房屋、建筑支撑、可站立地形、角色和前景。竖向远景没有视差；水平远景保留轻微视差，近处房屋和构件不随镜头漂移。
