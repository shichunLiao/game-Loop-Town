# 回环镇 · Demo 5

## 运行与继续进度

完整解压 Windows 包，双击同目录的 LoopTownDemo.exe。保留 LoopTownEngine.exe 和 LoopTownDemo.pck。无需另装 Godot。

标题选择「继续上一次探索」可沿用旧探索存档；「新探索（重新开始）」会重置本轮进度。继续游戏从最近点亮的路灯出发。已经拾取的记忆、居民委托、机关开闭和窗户状态会保存；死亡不会清空已收集的线索。

Godot 工程使用 4.6.3，导入 project.godot，F5 进入新版。

## 本轮变更

### 独立室内和线索

28 处可进入房屋分别对应独立的 .tscn 场景。靠近外门按 E，淡出后卸载街道并加载室内；室内左侧门按 E 返回对应街道门口。人物生命、墨光与同一个会话状态跨场景保留。未采用同地图剖面。

屋内纸页改为可调查的桌面线索，拾取后不再显示。统一记录物品标志和稳定拾取编号；补上井底真实记忆漏判的问题。旧存档已有的房屋纸页同样按原物品编号识别，不重复发放。

室内有真实地面、书架平台、家具和部分常驻居民，使用四类房间美术和不同陈设。28 个场景复用部分室内画面与布局，尚非 28 套全新室内原画。

### 房屋之后的新景层

在远景和可交互房屋之间增加 WorldRearScenery：石桥、温室院墙、教堂、运河仓库、蜡像炉墙、剧院吊景、井壁与根系、钟楼机械廊。新景层与房屋均固定在世界坐标；只有最远的天空与天际线保留视差。

### 建筑与道路机关

14 组有条件的道路改用建筑门、剧院防火门、井口检修门、排水闸或翻板桥。满足条件后，靠近按 E 进行开门/放桥操作；动画完成才解除道路碰撞。两端共用同一机关状态，开启后往返不必再次解锁，读档后仍保持开启。

未满足条件时按 E 检查，会记录道路调查。可以按日志提示询问附近居民；NPC 说明缺少的道具、印记或机关及其位置。地图仍按原来的 18 个区域和 23 段实体楼梯、连廊、井道连通。

### 任务与居民

- 10 步主线目标，自动随线索与剧情进展更新，日志保留已完成记录。
- 8 个居民委托：接取、进屋寻找纸页、返回交付、一次性恢复奖励。
- 47 处 NPC 配置，沿用 8 种角色外观；每个实例独立记录交谈状态、身份和委托。
- 头顶 ! 为可接委托，? 为可交付；L 打开任务日志，可选择追踪主线、委托或道路调查。
- HUD 显示当前目标、道路方向和估算距离；M 地图用金色菱形标出目标街区。
- 建筑内目标会先引导到对应外门，再引导到室内纸页；跨区目标按实体道路寻路。

### 阶段武器与攻击

| 解锁阶段 | 武器 | J | K（消耗 25 墨光） |
|---|---|---|---|
| 初始 | 墨页短刃 | 纸页三连击 | — |
| 获得剪刀 | 裁断大剪刀 | 交叉剪斩 | 剪刃突进 |
| 剧院印记 | 红线双剪 | 红线回旋斩 | 环身追加剪击 |
| 井底印记 | 井火钩刃 | 青色余火斩 | 余火突进重击 |
| 守钟笔记 / 缓时 | 钟钥细剑 | 钟刻穿刺 | 延长刺击并短暂缓时 |

武器拥有独立转轴，按蓄力、有效攻击、收势改变姿态；三连击包含正斩、反斩、回旋收尾。身体随攻击倾斜、前探与压低。命中使用实际攻击范围，每次挥动对同一目标仅结算一次；不同武器使用纸片、交叉刃光、红线、余火或钟刻特效。人物仍是初版剪纸式姿态动画，尚非逐帧手绘动画。

## 操作

| 按键 | 动作 |
|---|---|
| A / D，方向键 | 左右移动 |
| Space | 跳跃；解锁后二段跳 |
| W + J | 上挑 |
| 空中 S + J | 下劈，命中敌人后反弹 |
| 连续 J | 三连击 |
| K | 当前阶段武器技能 |
| E | 对话、读线索、进出室内、操作道路机关 |
| Shift | 解锁后冲刺 |
| W / S | 解锁后抓藤蔓攀爬 |
| S + Space | 穿下单向平台 |
| Q | 解锁后缓时，消耗 35 墨光 |
| H | 消耗 50 墨光，恢复 30 生命 |
| L / M / Tab | 任务 / 地图 / 笔记 |
| Esc | 暂停或关闭面板 |
| R | 回到路灯 |

## 交付内容与范围

Windows 可运行包、Godot 源码、素材包、全域地图和实际游戏画面。新增 5 张内置 imagegen 透明图集，共 20 个后排景物 / 武器 / 家具 / 门板单元；全项目 61 张环境与角色 PNG。提示词保存在 v5-art-prompts.json 和 v5-extra-art-prompts.json。

本轮进行了引擎导入、编译与实际运行画面预览；未进行完整剧情通关、全地图逐路游玩或自动化测试。仍保留一位初版 Boss、八类敌人和原有剧情结局，未新增完整 Boss 章节。战斗数值、角色动作及室内差异仍可继续细化。

## 扩展入口

- data/exploration/world.json：全部 69 个场景的几何、建筑、NPC 与出口。
- data/exploration/quests.json：主线、居民委托、道路提示与目标。
- data/exploration/weapons.json：阶段武器的伤害、范围、时序与配色。
- tools/dev/build_exploration_v5.py：室内、居民、任务、道路机关的编写来源；修改后运行 build_exploration_world.py 生成场景。
- scripts/exploration/exploration_journal.gd：任务追踪与道路导航。
- scripts/exploration/exploration_passage.gd：实体门与桥的操作、碰撞和保存状态。

运行包不包含个人配置、密钥、编辑器插件或微软字体文件，中文使用系统字体。
